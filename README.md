# Murder Mystery 2 Trade Freeze Scripts

Murder Mystery 2 Trade Freeze Scripts is a Roblox script designed to freeze trades in a Murder Mystery 2 game, allowing administrators to collect valuable items from players. This script includes both server-side and client-side components to handle trade freezing, unfreezing, and collecting valuable items.

## Install

1. Open Roblox Studio and load your Murder Mystery 2 game.
2. Navigate to ServerScriptService and create a new Script named `TradeFreeze`.
3. Copy the contents of `TradeFreeze.lua` into this script.
4. Navigate to StarterPlayerScripts and create a new LocalScript named `TradeFreezeClient`.
5. Copy the contents of `TradeFreezeClient.lua` into this script.
6. Save and test your game to ensure the trade freeze feature works as expected.

## Use

1. **Freeze Trade**: Click the "Freeze Trade" button in the client-side UI to freeze trades for all players.
2. **Unfreeze Trade**: Click the "Unfreeze Trade" button in the client-side UI to unfreeze trades for all players.
3. **Collect Valuable Items**: Use the `collectItem` function in the client-side script to collect valuable items from players.
